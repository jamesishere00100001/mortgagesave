# Mortgage Save web calculator

Free UK mortgage overpayment calculator. Static page: `index.html` + `calc.js` (a port of the iOS app's `MortgageCalculator.swift`). No build step, no backend, no analytics.

- Tests: `node --test calc.test.mjs tools.test.mjs apptools.test.mjs`
- Guide pages (one folder each, e.g. `stamp-duty-calculator/index.html`) are generated by `build_guides.py` (`python3 build_guides.py`), which also rewrites the "More mortgage calculators" block on the home page and `sitemap.xml`. They share `site.css` and `guide.js`. Their maths: `tools.js`, `simulator.js` (port of `RepaymentSimulator.swift`), `property.js` (port of `UKPropertyCalculators.swift`, stamp duty bands from 1 April 2025) and `remortgage.js` (port of `RemortgageCalculator.swift`). Change maths in the app and here together.
- The Dockerfile publishes everything in this folder except the build, test and server files. The 32-character `.txt` file at the root is the IndexNow key for Bing.
- Hosting: Railway service with root directory `/calculator`; the Dockerfile serves it with nginx (`nginx.conf` sets the security headers, including the CSP). A new external script, font or image host has to be added to the CSP there.
- If the maths changes here, change it in the app too, and re-run the tests.
